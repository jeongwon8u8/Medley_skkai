# 사전 검증 실험 (Pre-validation)

본 실험(NMT-4K-EEG + 임상 텍스트)에 들어가기 전에, 공개 EEG 데이터셋 4개로 연구 질문을 미리 확인한 실험입니다.

> **무엇을 했나.** 네 데이터셋(TDBRAIN, Mumtaz, PD-EEG, AD-EEG)에 같은 프로토콜을 적용했습니다. 19채널 · 0.3–75 Hz · 200 Hz · 5초 구간 → **frozen CBraMod**(3,800차원) → L2 로지스틱 회귀로 EEG-only 기준선을 만들고, 그 위에 임상정보를 결합한 뒤 **같은 EEG에 다른 환자의 차트를 붙이는 정보 교체 실험**으로 모델이 무엇을 보고 판단하는지 확인했습니다. 마지막으로 EEG 판단에서 크게 벗어나지 않게 하는 **근거 보존 결합 3가지**(A1 변화 폭 제한, A2 교체 정보 학습, A3 일관성 가중치)를 시험했습니다.
>
> **EEG-only 기준선 (AUROC):** Mumtaz 0.954 · TDBRAIN 0.929 · AD vs CN 0.821 (잡음 정리 시 0.871) · PD 과제 C 0.70 · AD vs FTD 0.61 · PD vs HC 0.58
>
> **핵심 결과**
> 1. 같은 "높은 기준선"이라도 근거의 질이 다르다. TDBRAIN은 나이·잡음과 무관하고 다른 기관으로 옮겨도 유지되지만, Mumtaz(63명)로 학습한 분류기는 TDBRAIN에서 판정이 뒤집혔다(0.32).
> 2. **단순 결합은 EEG 강도와 상관없이 지름길 정보를 따라간다.** 정답을 거의 알려 주는 변수(TDBRAIN의 BDI·rTMS·NEO 기록 유무, PD의 UPDRS, AD의 MMSE)를 넣으면 성능은 0.96-1.00이 되지만, 반대 그룹 차트를 붙이면 판정의 71-99%가 뒤집힌다.
> 3. 모든 데이터셋에서 **같은 그룹 남의 차트를 붙였을 때가 본인 차트일 때보다 성능이 높았다.** 모델이 그 사람의 정보가 아니라 그룹에 흔한 값을 단서로 쓴다는 증거다.
> 4. **근거 보존 결합의 효과는 EEG 기준선이 정한다.** 반대 차트를 따른 비율이 TDBRAIN(0.929)에서 75.9% → 0.4~2.8%로 줄었지만, PD matched(0.58)에서는 94% → 71%에 그쳤다. 같은 대상자(AD-EEG)에서 잡음만 정리해 기준선을 0.69 → 0.85로 올리자 22.6% → 6.1%로 좋아졌다.
> 5. 임상정보는 **과제와 관련 있으면서 EEG가 아직 담지 않은 정보**일 때만 정당하게 보완한다 (PD 과제 C의 나이: 0.709 → 0.764).

### 2.3 실행 순서

각 노트북은 위에서부터 한 셀씩 실행하면 됩니다. 공통 흐름은 다음과 같습니다.

```
설치 → Drive 연결 → CBraMod 준비 → 데이터 준비 → 스크립트 만들기
→ inspect(데이터 구조 확인) → select(피험자 선정) → extract(특징 추출, 시험 3명 → 전체)

→ relate(추가 B) → preserve(추가 A) → 데이터셋 고유 실험 → 보고서용 요약
```

## 3. 연구 질문과 실험 구성

팀 계획서의 문제의식: EEG와 임상정보를 함께 쓰면 성능이 오를 수 있지만, 성능이 올랐다는 사실만으로는 모델이 두 정보를 적절히 쓰는지, 학습하기 쉬운 텍스트에 기대는지 알 수 없다. 목표는 **EEG 근거를 보존하면서 관련 있는 임상정보만 선택적으로 반영해, 일부 데이터셋에서 EEG-only보다 나은 결합 모델**을 만드는 것이다.

| 질문 | 확인한 실험 |
|---|---|
| Q1. EEG만으로 얼마나 구분되고, 그 성능은 믿을 만한가? | 실험 1 EEG-only, 실험 2 잡음·나이 점검, 데이터셋 간 교차 평가 |
| Q2. 임상정보를 넣으면 모델은 무엇을 보고 판단하는가? | 실험 3 임상정보 조합, 실험 4 정보 교체 |
| Q3. EEG와 임상정보는 얼마나 관련되어 있는가? | 추가 B: EEG → 임상 변수 예측 |
| Q4. EEG 근거를 지키면서 임상정보의 이득을 얻을 수 있는가? 어떤 조건에서? | 추가 A: 근거 보존 결합, PD 과제 C, AD 고유 실험 |

**진행 순서**

| 순서 | 데이터셋 | 한 일 | 그 결과로 다음에 한 일 |
|---|---|---|---|
| 1 | TDBRAIN | 실험 1~4 | 누출 정보가 EEG를 대체함을 확인 → 다른 데이터셋에서도 재현되는지 확인 |
| 2 | Mumtaz | 실험 1·2 + 데이터셋 간 교차 평가 (임상정보 없음) | 내부 성능이 높아도 다른 기관에서 판정이 뒤집힘 → 기준선은 seed 반복 범위로 보고 |
| 3 | PD-EEG | 실험 1~4 + 추가 B·A + 과제 C | 근거 보존 결합 시제품(A1~A3)을 처음 만듦. EEG가 약하면 보존이 안 되고, 정당한 맥락(나이)이 있으면 보완됨 |
| 4 | AD-EEG | 실험 1~4 + 추가 B·A + AD 고유 실험 4개 | 같은 대상자에서 EEG 기준선만 올려 "기준선이 강해야 보존된다"를 직접 검증 |
| 5 | TDBRAIN (다시) | PD·AD와 같은 코드(`tdbrain_fusion.py`)로 실험 3·4 재현 + 추가 B·A | 가장 강한 기준선에서 근거 보존이 가장 잘 됨. 대신 결합 이득이 작음 |

## 4. 공통 프로토콜

### 4.1 대상 선정

| 항목 | 규칙 |
|---|---|
| 과제 | 이진 분류, **피험자 단위** 판정 (양성 = 1, 음성 = 0) |
| 안정 상태 기록 | EO·EC만 사용. 과제(task) 기록은 사용하지 않음 |
| 세션 | 피험자당 첫 세션만 (같은 사람이 학습·평가에 나뉘는 누수 방지) |
| 주 코호트 | **matched**: 음성 1명마다 같은 성별·나이 차 3세 이내 양성 1명을 가까운 순으로 짝지음 (seed 42). 나이를 지름길로 쓰지 못하게 함 |
| 보조 코호트 | **full**: 기준을 만족하는 전원 |
| 임상 변수 분류 | **맥락**(검사 전에 알 수 있는 배경), **증상 근접**(질환 증상을 직접 재는 척도), **누출**(한쪽 그룹에만 기록되어 값의 유무만으로 라벨이 드러나는 변수. `has_X` 0/1로 입력) |

### 4.2 EEG 전처리와 특징 추출

| 단계 | 설정 |
|---|---|
| 채널 | 19채널, Mumtaz 순서 (Fp1, Fp2, F7, F3, Fz, F4, F8, T3, C3, Cz, C4, T4, T5, P3, Pz, P4, T6, O1, O2). 10-10 표기(T7/T8/P7/P8)는 이름만 대응 |
| 기준전극 | 원본 유지, 재참조 없음 |
| 필터 | 0.3–75 Hz 대역통과, 50 Hz 노치 |
| 리샘플링 | 200 Hz |
| 구간 | 5초, 중첩 없음, 5초 미만 잔여 신호 제외 |
| 진폭 | μV ÷ 100 → 입력 `[19채널, 5패치, 200샘플]` (`5`는 1초 길이 시간 패치 5개) |
| 잡음 처리 | 구간 제거·ICA·clipping 없음. 고진폭 구간은 품질 점검용으로 표시만 |
| 특징 추출 | **frozen CBraMod** (원본 코드 + 원본 사전학습 가중치). `proj_out`을 Identity로 바꿔 `[B, 19, 5, 200]` 출력 → 5개 시간 패치 평균, 채널 유지 → **3,800차원** |

CBraMod를 고정한 이유: 추가 학습 없이 사전학습 표현 자체가 질환 정보를 담고 있는지 확인하기 위해서다. 실제로 학습되는 것은 뒤의 로지스틱 회귀뿐이다.

### 4.3 분류기와 평가

| 항목 | 설정 |
|---|---|
| 분류기 | StandardScaler(학습 fold로만 fit) + L2 로지스틱 회귀, C = 0.01, **5초 구간 단위 학습**, 임계값 0.5 |
| 피험자 점수 | 조건별 구간 확률 평균 → 조건 평균 (EO·EC 같은 비중, 한 조건만 있으면 그 값) |
| 교차검증 | 피험자 단위 층화 5-fold (shuffle, seed 42) |
| 반복 | 분할 seed 0~9로 10회 반복 → **평균 ± SD를 대표값**으로 사용 (Mumtaz부터 적용) |
| 지표 | AUROC(주 지표), balanced accuracy, sensitivity, specificity, F1, AUPRC, fold별 평균 ± SD, 구간 단위 성능 |

### 4.4 임상정보 결합 (실험 3)

| 항목 | 설정 |
|---|---|
| 결합 방식 | **스태킹**: EEG를 점수 1개(EEG-only 확률의 logit)로 요약 → 임상 변수와 함께 로지스틱 회귀(C = 1.0) |
| 누수 방지 | 학습 fold의 EEG 점수는 학습 fold 안의 내부 5-fold OOF로 다시 만듦. 평가 fold 점수는 실험 1과 같음 |
| 결측 | 학습 fold 중앙값 대체. 결측 여부 변수는 넣지 않음 (결측 비율 자체가 단서가 되는 것을 막기 위해) |
| 조합 | 맥락 + 증상 근접 변수의 모든 부분집합 |
| 중첩 선택 | 조합 선택도 학습 fold 안에서만 → 선택 편향 없는 "최상 조합" 성능 |
| EEG 비중 | 결합 모델 표준화 계수에서 \|EEG 계수\| / Σ\|계수\| (근사 지표) |
| 누출 대조 | 누출 변수는 조합에 섞지 않고 따로 평가 |

### 4.5 정보 교체 (실험 4)

평가 피험자의 EEG 점수는 그대로 두고 임상정보만 바꿔 넣는다. 다른 환자는 20번 뽑아 평균낸다 (seed 42).

| 조건 | 넣는 임상정보 | 확인하는 것 |
|---|---|---|
| 1. 미제공 | 없음 | EEG만의 판단 |
| 2. 본인 정보 | 본인 것 | 실제 결합 성능 |
| 3. 무작위 다른 환자 | 아무나 | 엉뚱한 정보에도 흔들리는지 |
| 4. 같은 그룹 다른 환자 | 양성이면 다른 양성 | 본인 정보가 아니라 그룹에 흔한 정보를 단서로 쓰는지 |
| 5. 반대 그룹 환자 | 양성이면 음성의 정보 | EEG와 차트가 반대일 때 어느 쪽을 따르는지 |

- **판정 변화:** 본인 정보일 때와 판정이 달라진 비율
- **차트를 따른 비율:** EEG-only 판정과 차트 방향이 다른 경우 중, 최종 판정이 차트 쪽으로 바뀐 비율 (TDBRAIN을 같은 코드로 다시 돌려 기존 값과 같음을 확인: 76.5% vs 75.9%)

### 4.6 추가 실험 B·A

| 실험 | 방법 |
|---|---|
| B. EEG–임상정보 관련성 | 피험자 평균 CBraMod 특징 → 임상 변수 (RidgeCV, alpha 10⁰~10⁵, 같은 outer 5-fold). **같은 그룹 안의 Spearman r**이 핵심 지표 (전체 상관은 그룹 차이만으로도 높게 나옴) |
| A1 변화 폭 제한 | 최종 logit = EEG logit + clip(결합 logit − EEG logit, ±δ), δ = 0.25 / 0.5 / 1 / 2 |
| A2 교체 정보 학습 | 학습 때 다른 환자 차트를 붙인 사본(정답은 본인 것)을 ρ배 추가, ρ = 0.5 / 1 / 2 / 4 |
| A3 일관성 가중치 | 차트 값이 "이 EEG로 예측한 값"(B의 Ridge)에서 z 표준편차 떨어져 있으면 w = 평균 exp(−z²/2τ²)만큼만 반영, τ = 0.1 / 0.25 / 0.5 / 1 / 2 |
| A2+A3 조합 | A2로 학습한 결합 모델에 A3 가중치 적용 (ρ = 2 / 4, τ = 0.5 / 1) |

**좋은 모델의 기준:** 본인 정보 AUROC는 EEG-only보다 높고, 반대·무작위 차트 AUROC는 EEG-only 근처를 유지하며, 차트를 따른 비율이 낮다.

## 8. 네 데이터셋에서 나온 규칙

| 규칙 | 근거 |
|---|---|
| 1. 단순 결합은 EEG 강도와 무관하게 지름길을 따른다 | 반대 차트를 따른 비율 76~100% (TDBRAIN 0.929에서도 75.9%). AD에서 기준선을 0.69 → 0.85로 올려도 98.7% → 96.1% |

## 10. 한계

- **임상정보를 숫자 변수로, 결합을 로지스틱 회귀로 했다.** EEG-언어 모델에서는 다르게 나올 수 있다.
- **근거 보존 방식은 스태킹 위의 단순한 시제품이고, 설정값(δ·ρ·τ)을 사후에 비교했다.** 절충 곡선으로 해석해야 한다.
- **누출 변수는 데이터셋 특성이다.** 음성 그룹에 검사를 하지 않아서 생긴 차이라, "실제 임상 텍스트가 과의존을 일으킨다"는 직접 증거는 아니다.
- **데이터셋마다 조건이 다르다.** 기록 길이(2~14분), 조건(EO·EC), 기준전극, 장비, 국가가 모두 달라 데이터셋 간 성능 차이를 질환 차이로만 해석할 수 없다.
- **대상자가 적은 데이터셋이 많다.** Mumtaz 63명, PD matched 56명, AD matched 38~44명이다. seed 반복은 같은 대상자를 다시 나눈 것이라 독립 반복이 아니다.
- **잡음 기준이 데이터셋마다 다르다.** AD-EEG는 100 μV 대신 200 μV를 주 기준으로 썼다.
- **교차검증 착시가 있다.** 1:1로 짝지은 코호트에서 정보 없는 변수(나이·성별)의 단독 AUROC가 0.5보다 낮게 나오고, 신호가 없는 회귀에서 음의 상관이 나온다. 모두 "정보 없음"으로 해석했다.
- **TDBRAIN 실험 3·4는 5-fold를 한 번만(seed 42) 수행했다.** ΔAUROC 0.002~0.008 수준의 맥락 변수 비교는 분할에 따라 순위가 바뀔 수 있다.
- **TDBRAIN education은 결측 비율이 그룹마다 다르다** (HC 29% 결측). 중앙값 대체가 단서가 되었을 가능성이 있다.
- **frozen encoder만 사용했고, 기존 EEG-language 모델(ELM 계열)이나 EEGNet 등과는 아직 비교하지 않았다.**

**주의 사항**

- **Mumtaz 노트북의 데이터 형식:** 노트북의 `mumtaz_cbramod_mdd.py`는 NEMAR `nm000114`의 BIDS 구조를 읽습니다. 보고서의 일부 수치(seed 반복, EO·EC 단독, 데이터셋 간 교차 평가, 학습 인원 축소)는 다른 배포본(파일명이 `MDD S1 EC.edf` 형식)으로 얻었으며, **이 실험들의 코드는 아직 저장소에 없습니다.** 두 배포본 모두 63명 (HC 30 / MDD 33), 기록 119개로 같습니다.
- **PD-EEG 추가 A의 설정값:** 노트북의 `pd_extra.py`는 τ = 0.1 / 0.25 / 0.5 / 1 / 2와 A2+A3 조합이 들어간 최신 버전입니다. 초기 실행(τ = 0.5 / 1 / 1.5 / 2)과 겹치는 설정의 결과는 같습니다.
- **TDBRAIN 실험 3·4는 두 가지 코드로 돌렸습니다.** 처음에는 `clinical_combo.py`·`swap_experiment.py`로, 이후 PD·AD와 같은 코드(`tdbrain_fusion.py`)로 다시 돌려 "차트를 따른 비율"이 같음을 확인했습니다 (76.5% vs 75.9%).
- **TDBRAIN zip 비밀번호, 참가자 표, EEG 데이터는 저장소에 올리지 마세요.** 데이터셋 사용 조건상 재배포가 금지되어 있습니다.
