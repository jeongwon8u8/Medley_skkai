# 연구 목표·향후 계획

## 연구 질문

동일한 EEG에서 임상정보만 바뀌어도 예측이 크게 달라지는 상황을 진단하고, EEG 독립 판단을 유지하면서 유용한 임상정보만 선택적으로 반영하는 결합 모델을 개발할 수 있는가?

## 단계별 진행

1. **Stage 1: EEG Foundation Model Evaluation** — Mumtaz/TDBRAIN, AD-EEG, PD-EEG 등 단독 성능 분석.
2. **Stage 2: EEG–Clinical Fusion** — 일반 맥락, 진단과 직결된 변수, 환자군 내 예측 과제에서 결합 비교.
3. **Stage 3: Clinical Reliance & Robustness** — EEG 고정, 임상정보 교체/결측/잡음에서 모델 변화 확인.
4. **Stage 4: Evidence-Preserving Fusion** — EEG 독립 경로 보존 및 임상정보 영향 제약; 현재 예비 실험을 출발점으로 정식 모델 검증.

## 2026-11 설계 검토 항목 (확정 전)

| 요소 | 검토 방향 | 참고 키워드 |
|---|---|---|
| Clinical | 구조화 수치 정보를 문장화, LLM 임베딩, leakage feature 분리 | TabLLM |
| EEG | CBraMod 및 채널 위치·뇌 영역 정보 보존 | CAPE |
| Fusion | EEG 기준 embedding alignment, 대비 학습, 임상 영향 제약 | SCL, SzXAI |

논문 약어/적합성/라이선스는 해당 논문 원문에서 별도 확인. 현재 표는 **참고 방향**이지 채택 및 효과 입증이 아닙니다.

## 우선 과제

- **PD-EEG**: 파킨슨병 환자의 인지 저하 예측. 보고된 113명, 현재 MoCA 기준 분류. '향후 더 빠른 저하'는 반복 추적 라벨이 확인된 경우에만 별도 Task로 정의.
- **TDBRAIN**: MDD 환자 rTMS 치료 반응 예측. 치료 전후 설문 기반 반응 기준, 예측 시점, 코호트 적격성을 명시.
- 두 과제 모두 예측 시점 이후 정보 누출/샘플 수 부족·class imbalance/외부 검증 가능성을 검토.

## 일정

| 기간 | 예정 업무 |
|---|---|
| 2026-11 | 선행 아키텍처 검토 마무리, 예측 과제/추가 데이터 탐색, 실험 프로토콜 확정 |
| 2026-12 | 모델 구현·개선, EEG/clinical/fusion 요소별 ablation |
| 2027-01 ~ 01-26 | 성능/강건성 검증, 오류 분석, 코드 정리, 논문 원고 |

## 최종 지향

AUROC만 개선하는 것이 아니라, EEG-only 기준의 독립 판단을 추적하고 정상 임상정보의 추가 가치와 잘못된 임상정보에서의 취약성을 구분해 평가한다. 국제학술대회 투고를 목표로 하되 투고·게재는 아직 확정된 성과가 아니다.
